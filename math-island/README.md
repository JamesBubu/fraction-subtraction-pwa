# 兔兔的數學冒險島

獨立的靜態教學入口，不需要安裝套件、建置或外部 CDN。開啟 `index.html` 即可使用；與原專案一起發佈時，路徑為 `/math-island/`。

## 操作與內容

- 拖曳旋轉小島、滾輪或雙指縮放；也提供旋轉、縮放、回全景按鈕。
- 四個地標和地圖下方的四個按鈕都能進入活動。
- 除法港口：156 ÷ 3 的拆箱、408 ÷ 4 的商中間補 0、125 ÷ 4 的餘數。倉庫、每艘船、位值表和操作紀錄同步。
- 位值工坊：百、十、一互換，總量固定為 123。
- 乘法果園：2–6 排、每排 11–15 棵，拆成十位與個位兩個矩形。
- 分數野餐地：同一條麵包從四等份細分為八等份，比較等值分數。
- 每個活動有一題遷移練習及錯誤提示。答對後將發現紀錄儲存在 `localStorage` 的 `math-island-v1`。儲存不可用時仍可操作。
- 鍵盤可選地點、操作活動、以 Esc 關閉，回到原本的地點按鈕。配合系統減少動態設定。

## 驗證

執行 `node math-island/verify.cjs`，涵蓋 4,500 組三位數除法，每一步數量守恆、商及餘數、商中間 0、完成後不再變動，以及資源與課程連結存在。

執行 `node --check math-island/island.js` 檢查 JavaScript 語法。

目前環境禁止本機 HTTP 監聽與瀏覽器開啟 file URL，因此尚未完成瀏覽器視覺與實際觸控驗證。響應式樣式已提供，但未宣稱通過實機驗證。

## 原始內容

島嶼與地標現在由 `scene3d.js` 以 WebGL 繪製真實立體模型，包含分層地形、屋頂瓦片、窗台花箱、碼頭繩索、燈塔、小船、果樹、圍欄及野餐區。使用方向光、2048 × 2048 陰影貼圖和 3 × 3 陰影濾波；海面與船隻有動態。動畫上限 30 fps，暫停、進入課程及隱藏頁面時停止更新。WebGL 不可用或 context lost 時，保留可操作的 SVG 地圖。參考自然島的探索互動形式，未使用對方程式碼或圖像。

本次以相同模型資料離線繪製預覽，檢查初始角度的構圖及幾何遮擋；此檢查不等同瀏覽器 WebGL、GPU 陰影或觸控實機驗證。

## 小島動畫與任務移動

- 海面改為網格波浪，搭配海岸白色浪花及流動水紋。
- 海豚約每 32 秒出現一次，躍出約 4 秒；鯨魚約每 53 秒浮出一次並噴水；海鷗約每 39 秒飛過一次。首次出現依序約為第 6、19、10 秒，時間只計算停留在地圖、未暫停且頁面可見的時間。
- 微風間歇吹動樹冠；任務開啟、頁面隱藏、暫停動態時停止場景時間。
- 點任務後，兔兔沿入口路線跳躍約 2–3 秒，到達後才開啟課程。提供「直接進入」；Esc 取消行程。移動中重複點擊不會累積課程開啟要求。
- 減少動態偏好或暫停模式下直接開啟任務。WebGL 不可用時同樣可直接使用全部課程。
- `node math-island/verify-animation.cjs` 驗證事件時序、20 組起終點路線，以及實際頁面控制程式的抵達開課、連點、略過、暫停、取消和隱藏頁面行為（DOM 模擬；不等同 GPU 畫面驗證）。
